# 3. CKB-VM et scripts

CKB-VM est une machine virtuelle compatible avec l’ISA RISC-V. Les scripts peuvent donc être écrits dans différents langages puis exécutés dans un environnement de vérification commun.

Le protocole sépare la vérification L1 du calcul plus riche des applications et des couches 2.
