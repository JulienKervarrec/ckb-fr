# 2. Cell Model et état vérifiable

Le Cell Model représente les données et leurs conditions de dépense comme des cellules. Cette organisation rend explicites l’état, la propriété et les transitions autorisées.

Elle permet à des applications de choisir leur logique de vérification sans imposer un langage unique.
