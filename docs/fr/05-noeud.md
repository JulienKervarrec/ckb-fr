# 5. Nœud, réseau et migrations

Le dépôt contient le binaire du nœud, la chaîne, le stockage, les migrations de base et les filtres de blocs. Les configurations et versions de réseau doivent être associées au bon état de la chaîne.

Le dépôt signale aussi l’envoi de traces vers Sentry en cas de panic Rust, option désactivable par configuration.
